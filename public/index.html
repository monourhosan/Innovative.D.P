How this Companion App Works
  1. Step 1: The Android app authenticates with /api/v1/auth/login using the Team Member's User ID and Password.
  2. Step 2: The app fetches the projects assigned to their Supervisor via /api/v1/member/projects.
  3. Step 3: The dynamic form fields (text, number, choices, GPS, dates) are rendered based on the project's form_schema_json.
  4. Step 4: Submissions are sent to /api/v1/member/submissions (with offline batch queue support).
  5. Step 5: The central backend saves the record, attaches metadata (Supervisor ID, Team Member ID, timestamp), and triggers an SSE broadcast to the Admin Live Dashboard!

REST API Contract for Companion Android Apps
Base URL: /api/v1

Complete endpoint reference for the companion Android applications. All requests accept and return JSON. CORS is fully enabled.

POST /api/v1/auth/login
Role: All (Admin, Supervisor, Member)
Authenticates user_id & password. Returns JWT token, user profile, and supervisor relationship. 
// Request Body
{
  "user_id": "SUP-1042",
  "password": "supervisor123"
}
GET /api/v1/supervisor/dashboard
Role: SUPERVISOR
Returns live supervisor stats: team members count, total submissions, today submissions, and per-member breakdown. 
Click "Run Test Call" to execute live against backend
GET /api/v1/member/projects
Role: TEAM_MEMBER
Returns active projects with full form_schema JSON for dynamic rendering on the Android app. 
Click "Run Test Call" to execute live against backend
POST /api/v1/member/submissions
Role: TEAM_MEMBER
Submits single collected form data or batch array of submissions for offline sync. 
// Request Body (Single or Batch Array)
{
  "project_id": 1,
  "answers_json": {
    "respondent_name": "Jannatul Ferdous",
    "respondent_age": 32,
    "gender": "female",
    "primary_water_source": "tube_well"
  },
  "client_timestamp": "2026-10-14T20:30:00Z"
}

Role: TEAM_MEMBER
Returns the Team Member's personal stats (today's count, total count, recent submissions list).

সিস্টেম ব্যবহারের সম্পূর্ণ নির্দেশিকা (Step-by-Step Guide)
Innovative Data Platform - মাঠ পর্যায় থেকে লাইভ ড্যাশবোর্ড পর্যন্ত সহজ গাইড
প্ল্যাটফর্ম পরিচিতি:
ইনোভেটিভ ডেটা প্ল্যাটফর্ম হলো মাঠ পর্যায়ের ফিল্ড সার্ভে এবং রিয়েল-টাইম সেন্ট্রাল তদারকির একটি আধুনিক ডিজিটাল প্ল্যাটফর্ম। এটি KoboToolbox XLSForm এবং সাধারণ Excel উভয় ফরম্যাট সমর্থন করে। সম্পূর্ণ অফলাইন-সক্ষম হওয়ায় দুর্গম এলাকায় ইন্টারনেট ছাড়াও ফিল্ড এনুমারেটররা নিরবচ্ছিন্নভাবে তথ্য সংগ্রহ করতে পারেন।
১. এক্সেল ফাইল আপলোড ও প্রজেক্ট তৈরি (Excel Upload & Project Creation) ধাপ ১

- বাম পাশের মেনু থেকে Projects ট্যাবে যান অথবা হোম পেজের "Upload Excel" বাটনে ক্লিক করুন।
- আপনার KoboToolbox XLSForm (সার্ভে ও চয়েস শীট সহ) বা সাধারণ এক্সেল ফাইলটি ড্র্যাগ করে ড্রপজোনে ছেড়ে দিন।
- সিস্টেমটি সেকেন্ডের মধ্যে কলামগুলো বিশ্লেষণ করে ডাইনামিক ফর্ম তৈরি করবে। ড্যাশবোর্ডে স্যাম্পল টেমপ্লেট ডাউনলোডের সুবিধাও রয়েছে।

২. ফিল্ড সুপারভাইজার অ্যাকাউন্ট তৈরি (Supervisor Account Creation) ধাপ ২

- মেনু থেকে Supervisors অপশনে গিয়ে + Add Supervisor বাটনে ক্লিক করুন।
- সুপারভাইজারের নাম, ইউজার আইডি (যেমন: SUP-1042), পাসওয়ার্ড দিন এবং তিনি কোন কোন সার্ভে প্রজেক্টের দায়িত্বে থাকবেন তা টিক দিন।
- সুপারভাইজার তার নিজস্ব লগইন দিয়ে তার অধীনস্থ টিম মেম্বারদের কর্মক্ষমতা ও সংগৃহীত ডেটা তদারকি করতে পারবেন।

৩. ফিল্ড টিম মেম্বার বা এনুমারেটর তৈরি (Team Members / Enumerators Setup) ধাপ ৩

- সুপারভাইজার বা এডমিন ফিল্ড এনুমারেটরদের অ্যাকাউন্ট (যেমন: TM-2001) তৈরি করবেন।
- মাঠ কর্মীরা এই আইডি ও পাসওয়ার্ড দিয়ে তাদের হ্যান্ডহেল্ড অ্যান্ড্রয়েড ডিভাইসে লগইন করবেন।

৪. মাঠ পর্যায় থেকে তথ্য সংগ্রহ (Field Data Collection & Mobile Simulator) ধাপ ৪

- ফিল্ড কর্মীরা মোবাইল অ্যাপে লগইন করে নির্ধারিত প্রজেক্ট সিলেক্ট করবেন।
- এক্সেল স্কিমা অনুযায়ী প্রতিটি প্রশ্নের উত্তর (টেক্সট, নম্বর, পছন্দ, ড্রপডাউন, জিপিএস লোকেশন) পূরণ করে সাবমিট করবেন।
- আপনি এখনই কোনো মোবাইল ডিভাইস ছাড়াই ওয়েবসাইটের Mobile Simulator ট্যাবে গিয়ে লাইভ সাবমিশন টেস্ট করতে পারেন।

৫. লাইভ ড্যাশবোর্ডে রিয়েল-টাইম তদারকি (Live Telemetry Monitoring) ধাপ ৫

- ফিল্ড থেকে সাবমিট হওয়া প্রতিটি রেকর্ড এই হোম পেজের Live Submission Stream-এ সেকেন্ডের মধ্যে দৃশ্যমান হয়।
- কোনো রিফ্রেশ বোতামে চাপ দিতে হবে না; সার্ভার-সেন্ট ইভেন্টস (SSE) প্রযুক্তির সাহায্যে ডেটা অটো-স্ট্রিম হয়।
- প্রতিটি সুপারভাইজারের আজকের অগ্রগতি ও মোট রেকর্ডের সংখ্যা লাইভ প্রগ্রেস বারে দেখা যায়।

৬. এক ক্লিকে সম্পূর্ণ এক্সেল রিপোর্ট ডাউনলোড (One-Click Excel Data Export) ধাপ ৬

- Submissions পেজে যান এবং Export to Excel (.xlsx) বাটনে ক্লিক করুন।
- সিস্টেম কয়েক সেকেন্ডের মধ্যে সমস্ত সংগৃহীত উত্তর, ফিল্ড এনুমারেটর, সুপারভাইজার, সময় এবং মেটাডেটা সহ পূর্ণাঙ্গ এক্সেল ফাইল তৈরি করে ডাউনলোড করে দেবে।
